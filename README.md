# DOOSUNG PAPER ACADEMY

두성종이 외부 고객용 종이 교육 사이트의 독립 프로토타입입니다. 공식 사이트나 승인된 교육 자료가 아닙니다.

## 실행

Node.js 18 이상에서 `npm start` 후 http://127.0.0.1:4173 접속. 외부 패키지 설치나 빌드가 필요 없습니다. 파일을 더블클릭하는 방식은 ES 모듈 보안 정책 때문에 지원하지 않습니다.

## 구성

- 6개 교육 챕터, 고정 헤더, 대화상자 목차
- 화면 높이 단위의 14개 장면, 스크롤 스냅 전환, 장면 진입 애니메이션, 현재 페이지 표시 및 이전·다음 버튼
- 평량·규격·장수 중량 계산기, 종이결 접힘 비교
- 인쇄·후가공 5가지 개념 비교, 용도별 선택 가이드
- 여유·회전 조건을 반영한 동일 방향 격자 재단 시뮬레이션
- 5문항 퀴즈와 개별 해설·재도전
- 모바일 레이아웃, 키보드 조작, 화면 읽기 레이블, 동작 줄이기 설정 대응

`npm test`로 계산식과 재단 경계 사례를 검증합니다.

## 장면 전환

브라우저 기본 스크롤 스냅으로 각 화면 시작점에 정렬합니다. 계산기·종이결·후가공·재단은 독립된 장면입니다. 화면보다 긴 내용은 장면 안에서 끝까지 스크롤할 수 있으며, 이후 다음 장면으로 이어집니다. 휠·터치·키보드를 강제로 가로채지 않으며, 하단 이전·다음 버튼과 기존 목차로 바로 이동할 수도 있습니다. 동작 줄이기 설정에서는 진입 애니메이션과 부드러운 스크롤을 생략합니다.

## 배포

GitHub Pages에서 Deploy from a branch → main → /(root)를 선택합니다. `.nojekyll`을 포함하므로 `.mjs` 모듈을 그대로 제공합니다. 모든 경로는 상대 경로로 프로젝트 Pages 주소에서도 작동합니다.

## 콘텐츠와 권리

모든 시각 자료는 CSS와 SVG로 자체 제작한 개념 이미지입니다. 외부 사진, 제품 사진, 로고 파일, 웹폰트, 추적 도구를 사용하지 않았습니다. 실제 제품의 색·질감·인쇄 결과를 보증하지 않습니다. 회사 연혁, 제품명, 가격, 판매 정책, 상담 경로를 창작하지 않았으며 소개 영역은 승인 자료로 교체할 예시로 표시했습니다. 브랜드 명칭은 요청에 따라 교육 시안을 식별하기 위해 사용했습니다. 공식 공개 운영 전 브랜드·교육 내용의 권리 및 정확성 검토가 필요합니다.

## 계산의 한계

중량은 이론값이며 수분·제조 공차를 반영하지 않습니다. 재단은 전체 조각이 동일 방향인 두 가지 격자 배치만 비교합니다. 혼합 배치 최적화, 종이결, 인쇄 물림, 도련, 칼날 손실, 제본 여유는 자동 적용하지 않습니다. 장수가 600장을 넘으면 그림은 영역 요약으로 표시하지만 산출 장수는 유지합니다.

로그인, 신청, 구매, 실제 제품 데이터 연동 및 서버 저장은 없습니다. 입력과 퀴즈 답은 브라우저 메모리에서만 처리됩니다.
